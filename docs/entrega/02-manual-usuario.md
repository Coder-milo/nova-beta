# Manual de usuario

## Inicio de sesión

1. Abre la URL pública de NOVA CRM.
2. Escribe tu correo institucional y contraseña.
3. Si no recuerdas la contraseña, usa **Recuperar contraseña**.
4. Al entrar, confirma que el nombre y el rol del menú lateral son los tuyos.

No compartas contraseñas ni enlaces de restablecimiento. Cierra sesión en
equipos compartidos.

## Portal del estudiante

El estudiante usa solo las áreas relacionadas con su propio proceso:

| Sección | Qué hacer |
|---|---|
| Inicio | Revisar progreso, alertas, plataformas y siguiente paso recomendado. |
| Mi proceso | Completar perfil laboral, CV, LinkedIn, portafolio y habilidades. |
| Mis postulaciones | Consultar estado, fecha, empresa, cargo y filtros de oportunidades. |
| Hoja de vida | Revisar, editar o descargar la hoja de vida disponible. |
| Documentos | Subir o descargar los documentos solicitados. |
| Calendario y actividades | Consultar reuniones, entrevistas, actividades y fechas. |
| Mensajes | Hablar con administración; la conversación con el equipo está disponible como contacto principal. |
| Notificaciones | Abrir una notificación para llegar a la postulación, mensaje o área relacionada. El contador de campana muestra las no leídas. |
| Configuración | Cambiar idioma y preferencias personales. Los estudiantes nuevos se muestran inicialmente en inglés. |

### Postularse a una vacante

1. Abre **Mis postulaciones** o la vacante recomendada.
2. Lee requisitos, modalidad, empresa y fecha de cierre.
3. Revisa que tu perfil y CV estén actualizados.
4. Confirma la postulación solo si deseas continuar.
5. Sigue el estado desde **Mis postulaciones** y atiende las notificaciones.

## Uso para empresas

Las cuentas empresariales acceden al portal de empresa para:

- actualizar datos de su empresa;
- crear o editar vacantes propias;
- revisar los candidatos vinculados a sus vacantes;
- mantener la información de contacto actualizada.

Una vacante captada públicamente puede quedar pendiente de revisión antes de
mostrarse a estudiantes. Esto protege la calidad de las oportunidades.

## Chat y asistencia

El chat orienta sobre navegación, documentos, CV, vacantes y proceso de
empleabilidad. No debe usarse para compartir secretos, contraseñas o datos de
terceras personas. Las solicitudes administrativas se deben resolver con el
equipo por los canales oficiales.

## Buenas prácticas diarias

- Actualiza el CV cuando cambie experiencia, formación o información de contacto.
- Revisa notificaciones y calendario cada día hábil.
- Registra postulaciones externas cuando el equipo te lo solicite.
- Usa nombres y datos reales; evita documentos duplicados.
- Reporta un dato incorrecto a administración, no intentes modificar registros de otros usuarios.
